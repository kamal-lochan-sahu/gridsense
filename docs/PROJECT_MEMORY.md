## Decisions
- Training runs on GitHub Actions, not on Render (512 MB RAM); Render only serves. Hugging Face Spaces, Cloudflare Workers and Supabase were checked and not adopted.
- forecast.json is published as an asset of the `forecast-data` release, **not** as a git branch: Vercel builds every pushed branch and the data-only `data` branch failed every time ("Root Directory frontend does not exist"). The backend keeps the old branch URL only as a fallback.
- Model choice is automatic per country: the simplest model within 3 % of the best backtest MAPE. Prophet stays in the pool (Kamal wants it) and is chosen when it earns it.
- Temperature comes from Open-Meteo: ERA5 archive for the long history, Forecast API for the last 14 days and the next 3 (the Forecast API alone returned ~50 days of nulls).
- README and docs are written once, at the end of the project.
- Git history: recommendation is to keep it (it is clean); a 3 MB icon blob and two debug commits remain. Final call undecided.

## Key findings (real ENTSO-E data, autumn 2026)
- Default Prophet and ETS lost to copying last week; a level-adjusted naive model won in three countries because the load drifts in autumn.
- Temperature and a regression model help modestly; error correction removes most of the low bias in France and Poland but adds noise in Germany.
- Against the TSOs (7 days to 2026-10-26, error %, GridSense / TSO / same hour last week): Germany 2.53 / 3.36 / 2.91 (ahead), France 3.05 / 1.68 / 9.69, Spain 2.48 / 1.08 / 2.89, Poland 2.47 / 1.61 / 2.29 (the baseline was slightly better on the last five days). The gap to the TSOs is every day, not a few days.
- Live champions on 2026-10-27: Germany naive_level, France ensemble_temp_adj, Spain naive_level_adj, Poland naive_level_hourly. Holiday handling worked live: on 19 Oct (a week after Spain's 12 Oct holiday) last-week copying was 15 % off, GridSense 2.4 %.
- 2026 national holidays used: Spain 12 Oct and 8 Dec; France and Poland 11 Nov; Germany 3 Oct (Saturday), 25 and 26 Dec. 1 Nov 2026 is a Sunday.
